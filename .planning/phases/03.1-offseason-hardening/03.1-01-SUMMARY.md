## Decisions Made
- D.isOffseason on `d` (not a global) because mergeHistoricalData receives `d` as a parameter and can reference it without a global read
- D.lastSeason set to null in buildCurrentSeasonData (before historical data exists), then overwritten in mergeHistoricalData — avoids the value being stale when buildStats is called before history loads (buildStats checks `D.isOffseason&&D.lastSeason`, both must be truthy)
- `week:null` instead of `week:0` — zero would be a valid week number, null explicitly means "no data"
- Champion in buildStats changed from `D.champions[0]` to `D.champions[D.champions.length-1]` — champions are pushed in chronological order; index 0 is the oldest
