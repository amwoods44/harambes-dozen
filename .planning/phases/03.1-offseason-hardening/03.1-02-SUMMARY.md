## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 2 - Missing Critical] Added scoring and matchups to dirty tabs after mergeHistoricalData**
- **Found during:** Implementation self-review (after Task 2)
- **Issue:** scoring and matchups were not in the dirty tabs set that fires after mergeHistoricalData runs. The offseason fallback vars check `D.lastSeason` which is null on first render and set during historical load. Without re-render, the fallback would never actually display on tabs the user was already viewing.
- **Fix:** Added 'scoring' and 'matchups' to the forEach that populates dirtyTabs in loadHistory()
- **Files modified:** index.html (line 2766)
- **Verification:** Confirmed dirty tabs list now includes both tabs; grep verified change
- **Committed in:** 297f9ee (separate fix commit)
