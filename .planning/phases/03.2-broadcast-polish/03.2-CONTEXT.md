# Phase 3.2: Broadcast Polish - Context

**Gathered:** 2026-04-01
**Status:** Ready for planning
**Source:** Full visual audit of all 18 tabs at desktop (1440px) and mobile (375px)

<domain>
## Phase Boundary

Transform every screen from "works correctly" to "obsessively crafted." The bar: a leaguemate opens this and says "one person built this? It's better than any fantasy app I've ever seen." That feeling comes from hundreds of small details being right — spacing, transitions, hover states, typography hierarchy, information density, visual rhythm. No new features. Only craft.

</domain>

<decisions>
## Implementation Decisions

### 1. Spacing & Visual Rhythm
- **D-01:** Establish a strict section spacing rhythm: 24px between major sections (broadcast headers), 12px between items within a section, 8px between tight elements (badges, pills). Currently spacing is ad-hoc — some gaps are 4px, some 20px, some 16px, creating visual noise.
- **D-02:** Every broadcast header (`.bh`) should have consistent margin-top of 24px. Currently varies between 8px and 20px across tabs.
- **D-03:** Card padding should be consistent: 16px on desktop, 12px on mobile. Currently varies from 10px to 20px.

### 2. Typography Hierarchy
- **D-04:** Each tab should have ONE dominant visual element — a number, a name, a stat — that's significantly larger than everything else. Currently most tabs have everything at the same "medium" size. The eye has nowhere to land.
- **D-05:** Power Rankings: the power score circle (currently 48px, showing "0" or a number) should be the hero — 64px, bold, with a subtle glow. It's the most important number on the page.
- **D-06:** Matchups: the scores (161.06 vs 145.62) are the right size and dominate correctly. This is the template for how other tabs should work.
- **D-07:** Contracts stat cards (188 CONTRACTED, etc.) are good hierarchy. Keep this pattern.
- **D-08:** GM Dashboard: the 12-16 record should be larger and the first thing you see. Currently it's the same size as WIN%, PPG, TITLES.

### 3. Transitions & Motion
- **D-09:** Tab content should fade in when switching tabs. Currently innerHTML swap is instant. Add: `.panel.active { animation: fadeIn 0.2s ease-out; }` with `@keyframes fadeIn { from { opacity: 0; transform: translateY(4px); } to { opacity: 1; transform: translateY(0); } }` — subtle enough to feel smooth, fast enough to not feel laggy.
- **D-10:** Roster team cards should animate open with a slide-down when expanded. Currently they pop in instantly.
- **D-11:** Counter animations already exist (CountUp.js). Extend to more number elements — stat cards in Contracts, the "100" temperature gauge in Pulse, the "168 MOVES" in Moves.
- **D-12:** The Power score circles should have a subtle pulse animation when the tab first renders.

### 4. Hover States & Interaction Feedback
- **D-13:** Every clickable element needs a hover state. The three collapsible sections in Trades (Trade Record, Capital, Trade Partners) have onclick but no cursor:pointer and no hover feedback. Fix: add cursor:pointer + a subtle background lighten on hover.
- **D-14:** Player names that open the profile modal should have a distinct hover state — color shift to the accent red, slight underline. Currently they look identical to non-clickable text.
- **D-15:** Team cards in the cast strip should lift slightly on hover (transform: translateY(-2px)) with a box-shadow increase. Currently they just change cursor.
- **D-16:** Nav tab buttons need a more visible active state. The red underline exists but it's thin and subtle. Make it bolder — 3px solid var(--a) with a slight glow.
- **D-17:** Keeper sheet column headers should show a hover state indicating they're sortable (background lighten + cursor:pointer).

### 5. Card & Section Consistency
- **D-18:** Standardize card styles across all tabs. Currently there are at least 4 different card patterns: Contracts uses dark cards with colored borders, GM uses outlined cards with stat grids, Awards uses gradient-topped cards, Trades uses inline rows. Define ONE card base style and THREE variants (stat card, content card, action card).
- **D-19:** All horizontal scroll strips (Tagged players, Expiring players, Top Assets in Contracts) should have a subtle gradient fade at the right edge to indicate scrollability. Currently they just clip.
- **D-20:** Broadcast headers (`.bh`) should have consistent styling. The red tag + accent line pattern is good but some have extra margin, some are squeezed.

### 6. Hero Section (First 3 Seconds)
- **D-21:** The hero needs more visual weight. "HARAMBE'S DOZEN" is large but the area between the title and the cast strip feels empty. The LEAGUE LORE card is small and centered — it should be wider and more commanding.
- **D-22:** The countdown clock in the header is good but could be more dramatic. The green box feels like a status badge, not a countdown. Consider: larger numbers, the word "UNTIL" before "NFL KICKOFF".
- **D-23:** The stat strip (2025 Champ, Most Points, Total Trades, Avg PF, Rookies Drafted) needs better card treatment. Currently they're flat text in a horizontal row. They should feel like ESPN's bottom-screen stat ticker — more contrast, slight card elevation, separator lines.
- **D-24:** Cast strip (12 team avatars) is good but could use subtle separator after every 4th team to break up the visual density.

### 7. Loading & Empty States
- **D-25:** The initial loading screen ("BUILDING DASHBOARD...") should feel cinematic. Currently it's a centered spinner with text. Consider: the Harambe logo pulses, a progress bar fills, the text changes from "CONNECTING TO SLEEPER..." → "LOADING ROSTERS..." → "BUILDING DASHBOARD..." — making the wait feel like something is happening.
- **D-26:** Tab "Loading..." messages (for historical data still loading) should use a subtle skeleton pattern — ghosted rows that match the layout of the tab content — not bare text.
- **D-27:** The "No draft data" empty state should never show. If current year has no draft, show last year's. If no year has a draft, show a meaningful message: "Rookie draft not yet completed for 2026" with the Harambe logo watermark.

### 8. Mobile Polish
- **D-28:** The hero on mobile wraps "15 KEEPERS * PICK TRADING * BONUS SCORING" awkwardly with the bullet on its own line. Fix text wrapping or reduce font size.
- **D-29:** Cast strip on mobile only shows 4 team avatars at a time with no indication there are 8 more to scroll. Add horizontal scroll indicator dots or a subtle gradient fade.
- **D-30:** Stat strip on mobile truncates to 3 items. The truncated items should still be accessible via horizontal scroll.
- **D-31:** Contracts team filter pills wrap to 4 rows on mobile. Consider a horizontal scroll instead.
- **D-32:** Navigation on mobile: "MATCHU..." is truncated. Dropdown labels (INTEL, HISTORY, LEAGUE) take 3 slots but only show labels. On mobile, consider icon-only nav or a hamburger menu.
- **D-33:** Keeper sheet table needs horizontal scroll on mobile — currently columns are crushed or hidden.

### 9. Tab-Specific Polish

**Power Rankings**
- **D-34:** The "REBUILD MODE" tier label sits alone with no visual context. It should feel like a broadcast chyron — angled background, stronger color.
- **D-35:** Power ranking cards show "0-0 · 0 PF · Age 25.2" — in offseason this is correct but the "0 PF" feels wrong. Show last season's total PF instead.

**Rosters**
- **D-36:** Collapsed roster cards are solid but the badge pills (WHEELER-DEALER, DRAFT HOARDER, etc.) are very prominent. These are personality tags, not rankings — they should be subtler (smaller, less saturated) so the team name dominates.
- **D-37:** When expanded, the player thumbnails strip at the top has no labels visible until you look closely. Consider showing just the surname below each thumbnail.

**Matchups**
- **D-38:** Week selector numbers (1-17) are small and dense. The active week should have a red accent, not just a border. Inactive weeks need more spacing.
- **D-39:** Game of the Week card is great — the large scores with team avatars and margin bars. This is the broadcast template. Every matchup card below should echo this quality.

**Draft**
- **D-40:** Draft board cards are actually quite good — position badges, college, NFL team logos. The round labels on the left ("ROUND 1 / 9/12 hit") are a nice touch. Minor: the hit rate should be more visible (maybe color-coded: green for good, red for poor).

**Trades**
- **D-41:** Trade cards with player headshots and grades are the best visual element in the app. The A+/B/F letter grades with gradient circles are broadcast quality. Keep and amplify this pattern.
- **D-42:** The collapsed sections (Trade Record, Capital, Trade Partners) look like dead sections. They need a subtle "click to expand" indicator — a chevron icon, a + icon, or a border that glows on hover.

**Scoring**
- **D-43:** Heat map is excellent — color-coded cells with score numbers. The "LOW MID GOOD ELITE" legend at the bottom is too far from the data. Move it closer or make it a floating legend.

**Age Map**
- **D-44:** Stacked bar chart is clean and readable. Good use of the green/yellow/red color coding. The Dynasty Scatter and Windows sections below add real depth. This tab is one of the best — minor polish only.

**Awards**
- **D-45:** Award cards with icons and descriptions are good. The gradient top borders by team color are a nice touch. The "No voting, no bias — the numbers decide everything" tagline is excellent. Hall of Fame section could use the same card treatment instead of a flat list.

**Analytics**
- **D-46:** H2H Matrix is a wall of numbers. The color coding helps but it needs more visual breathing room. Consider: thicker row dividers every 4 rows, a sticky first column on scroll, larger header text.
- **D-47:** The multiple sections (H2H, All-Play, Consistency, Pythagorean, SOS) are all tables/charts stacked vertically. They need broadcast headers between them and visual separation.

**GM Dashboard**
- **D-48:** The stat grid per manager (RECORD, WIN%, PPG, TITLES, TRADES, LUCK, PICKS, AVG AGE) is dense but functional. The career strip ("Career: 71W-41L · 9389 PF · 2 Titles") is a great addition. Make it more prominent — it's the lifetime stat line.
- **D-49:** The lifetime achievement badges look great. But the "LIFETIME ACHIEVEMENTS" label is too small (9px). Make it 11px with more letter-spacing.

**Rivals**
- **D-50:** Dominance bars are bold and clear. The "PROUD BOYS OWNS THIS RIVALRY" text in caps is very ESPN. This tab works well — just needs consistent spacing and card treatment.

**Contracts**
- **D-51:** The best tab in the app. Stat cards, scroll strips, team health bars, cliff chart, keeper sheet — it has everything. Minor polish: the keeper sheet header row needs more visual weight to feel like a proper table header (darker background, stronger border).

**Trophies**
- **D-52:** Championship banners are the best visual element in the app. The pennant shape with team color, year, trophy icon, and "DEF. [opponent]" is broadcast perfection. Standings Race section is ready but the canvas area looks empty before clicking Play — consider a "PRESS PLAY TO WATCH THE 2025 SEASON UNFOLD" message inside the canvas.

**War Room**
- **D-53:** Deadline cards are functional but plain. They should feel urgent — the exemption deadline (54 DAYS AWAY) should pulse or have an accent color based on urgency (green = 60+, yellow = 30-60, red = <30).

**Constitution**
- **D-54:** Actually excellent. Clean layout, article navigation sidebar, monospace values. This is the quality bar the rest of the app should reach.

**Pulse**
- **D-55:** League Temperature gauge (100, ON FIRE) is a good concept but the circular gauge looks like a basic div. Should feel like a broadcast temperature dial — maybe a semicircular meter or a thermometer.
- **D-56:** Championship story cards have good structure. The timeline dots and year headers work well. Needs consistent card elevation.

**Chronicle**
- **D-57:** Timeline layout with year headers and event cards is good. The colored dots by event type (red for records, gold for championships, blue for exemptions) create visual rhythm. Minor: the year dropdown + year buttons feel redundant — pick one.

### Claude's Discretion
- Exact easing curves for transitions (ease-out vs cubic-bezier)
- Whether to add a subtle background texture/pattern to the hero
- Exact breakpoint for mobile nav changes (375 vs 428 vs 480)
- Whether sort indicators use unicode arrows or SVG
- Skeleton loading pattern (shimmer vs solid gray blocks)
- Whether to add a "data freshness" indicator beyond the ticker timestamp

<code_context>
## Existing Code Insights

### What's Already Good (Protect These)
- Championship banners in Trophies — pennant shape, team color, trophy icon
- Trade cards with player headshots and letter grades (A+/B/F gradient circles)
- Awards cards with gradient top borders and icon/description layout
- Matchups Game of the Week — large scores with team avatars and margin bars
- Draft board cards — position badges, college info, NFL team logos
- Constitution layout — article navigation, clean table formatting
- Rivals dominance bars — bold, clear, ESPN tone
- Contracts stat cards — large numbers, color-coded, clear hierarchy

### What Needs the Most Work
- Spacing inconsistency across all tabs (the #1 systemic issue)
- No transitions/animations on tab switch or content reveal
- Missing hover states on collapsible sections, some clickable elements
- Typography hierarchy — most tabs lack a dominant visual element
- Mobile navigation truncation and layout cramming
- Loading/empty states are bare text instead of designed experiences

### CSS Architecture Notes
- All colors use CSS custom properties (`var(--a)`, `var(--g2)`, etc.)
- Spacing tokens exist (`--sp-1` through `--sp-10`) but aren't used consistently
- Broadcast headers use `.bh` class with `.bh-tag`, `.bh-acc`, `.bh-line`, `.bh-sub`
- Most inline styles in render functions — changing base CSS classes will propagate widely
- Adding new CSS to `<style>` block propagates to all tabs automatically

</code_context>

<specifics>
## Specific Ideas

- Constitution tab is the quality bar. Every other tab should feel like it got the same level of attention.
- The trade cards with headshots and grades are the "wow" moment. Find ways to bring that visual intensity to other tabs.
- Championship banners are unforgettable. They should be one of the first things a new visitor sees.
- The analytics H2H matrix is a wall of data that would impress a stats nerd but overwhelm a casual fan. Both audiences need to be served.
- Mobile is where leaguemates will actually use this (checking on their phone in the group chat). Mobile polish is not secondary — it's primary.

</specifics>

<deferred>
## Deferred Ideas

- **Custom loading animations per tab** — each tab could have a themed loading skeleton (draft cards skeleton, trade cards skeleton). Too much scope for this phase.
- **Dark mode toggle** — dark is the brand, but some users browse in sunlight. Future consideration.
- **Sound effects on interactions** — fun but absolute last priority per project constraints.
- **Parallax scrolling on hero** — flashy but potentially performance-heavy on mobile.

</deferred>
